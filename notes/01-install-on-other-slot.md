# Guide to install same version of OxygenOS in other slot

## Prerequisites
- OxygenOS version zip

## Steps
### 1. Turn on Developer option

Go to Settings > About phone > Version > Tap version 7-8 times

### 2. Turn off WiFi and internet

### 3. Clear data of Updater app

Go to Settings > Apps > press `Show system apps` from 3-dots on top right > Updater > Clear app data

### 4. Local install

Go to Settings > About phone > Update > select `Local install` from 3-dots on top right

### 5. Reboot after completion
